# Project Instructions

## Sudo / admin read-only roadblocks

This is a standing rule for all future sessions in this project.

When a needed check requires interactive sudo or operator terminal execution:

1. Write the exact command block, syntax-check it without executing it, and label it `PROPOSED — NOT APPLIED / NOT EXECUTED`. The commands must be non-modifying.
2. Log it clearly as `OPERATOR MUST RUN IN TERMINAL`, including the file path where the block was saved.
3. Do not stop. Immediately continue with other useful work that can be done from saved files and the candidate tree only.
4. Prefer directions that do not require sudo, such as drift analysis, missing-helper location, Evidence Explorer spec slices, blocker lists, and handoff notes.
5. Never treat a sudo requirement as the end of the turn.
